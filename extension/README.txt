安装浏览器助手（只需一次）

Chrome：
1. 地址栏打开 chrome://extensions
2. 打开右上角“开发者模式”
3. 点击“加载未打包的扩展程序”
4. 选择本 extension 文件夹

Edge：
1. 地址栏打开 edge://extensions
2. 打开“开发人员模式”
3. 点击“加载未打包的扩展程序”
4. 选择本 extension 文件夹

此文件夹由桌面软件自动释放和修复，请不要移动。使用时先运行桌面控制台，再打开已经登录的 grok.com。
自动运行期间不要手动操作目标 Grok 标签页。

升级已有版本：复制新版文件后，在扩展管理页面点击本扩展的“重新加载”。

0.4.0 会使用浏览器调试权限产生真实的鼠标悬停与点击，以便打开 Grok 的图片用途菜单并点击发送箭头。运行时浏览器可能显示“正在调试此浏览器”的提示条，这是本助手正常工作所需；关闭提示条或拒绝权限会导致自动点击失败。

0.4.1 修复浏览器调试提示条出现后页面下移，造成第一次缩略图悬停坐标偏移的问题。

0.5.0 会把自动化使用的 Grok 标签页维持为活动网页状态。切换到其他标签页时，上传、用途设置和提交仍会继续运行，但不要关闭或刷新该 Grok 标签页。
